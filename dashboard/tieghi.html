This first Tieghi build works from Directus receipt-book data already in the system. It shows monthly receipt income by receipt type, proposes the next print range from usage, stores confirmed print batches, and can generate virtual receipts for a month while reserving those serial numbers.

Six-Month Print Planning

Ask M-CodeZ for the next 6 months requirement. The system reads the last 6 months of receipt usage for the selected receipt type, adds 5%, and proposes the next safe print range without duplicate serials.

Virtual Month Fill

Add a virtual receipt batch for a month. M-CodeZ uses the selected month history to estimate an average receipt amount, mixes in cancelled zeros, finds safe receipt numbers, and writes them to Directus so those numbers can no longer be printed.

Stored Print Orders

Every confirmed batch is treated as reserved straight away, even before physical printing, so the next batch cannot overlap the same serial range.
